# Storyline

Start with two answers: **who is in the room** and **what should they do after the last slide?**

Structures
| Use | Sequence |
|---|---|
| Sales / proposal | Their situation → the cost of the problem → our solution → proof → options → next step |
| Pitch / investment | Problem → solution → traction (numbers) → market (sourced) → business model → team → the ask |
| Internal update | Headline result → what worked → what did not → decisions needed |
| Training | Why it matters → steps → example → practice → recap |

Rules
- Write the headlines first, in order. Read them alone: they must tell the story.
- One slide = one message. 8–12 slides for 10–20 minutes is typical.
- End with one clear ask (a meeting, a pilot, an approval), never "Questions?" alone.
- Confirm the headline list with the owner before writing every slide.
