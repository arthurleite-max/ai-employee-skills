# Pitfalls

- **A feature list instead of promises**: nobody can test "AI-powered insights".
- **Vague safety rules**: "be careful" cannot fail a test, so it is never followed.
- **Only tested on the best model**: free chat models are where most users are.
- **Placeholders copied literally** by the model ("[name]", "[last 4]").
- **Summary before the maths**: the headline ends up contradicting the table.
- **The model's own clock** used instead of the date the user gave.
- **Real data or internal names** left in examples, or quoted in a table of "what to refuse".
- **Waiting for a tool** (code, zip, upload) in a chat that has none: write the files as text.
- **Copying another project's files** instead of learning from them.
- **A script that needs installing**, the internet or the user's passwords.
- **A compact edition that depends on files** the user will not have.
- **Promising actions the AI cannot take** at level 1 (sending, booking, calling).
- **Leftover TODOs**, broken file references, caches in the zip.
