# Landing pages

A landing page has one offer, one audience and one action. Everything on it serves that action.

## Brief (ask only what is missing)

- Offer: what exactly, for whom, price or "[PRICE — you confirm]", limits (dates, places) if real.
- Action: call, WhatsApp, booking link, form (which fields).
- Traffic: ads, Instagram bio, Google, email. The headline should match what brought them.
- Facts available: from the profile and the owner. List them; everything else becomes a placeholder.
- Proof: real reviews, testimonials with permission, photos.

## Structure (adapt; drop what has nothing true to say)

1. **Hero**: headline (what + for whom + the main reason), one supporting line, primary CTA, real
   photo or illustration of the actual service.
2. **Problem / situation** in the visitor's words (2–4 lines).
3. **The offer**: what is included, how it works (3 steps if it truly is a process), where and when.
4. **Proof**: rating and count as stated, named testimonials, credentials.
5. **Objections / FAQ**: price, time, "is it for me?", cancellation, location, parking. Only real answers.
6. **Final CTA** with what happens next.
7. **Footer**: name, address, contacts, privacy notice link.

## Design floor

- Brand colours and fonts from the profile; otherwise one readable font family, a base colour, one
  accent with enough contrast.
- Mobile first: single column, CTA reachable with the thumb, tap-to-call / WhatsApp.
- One memorable idea (an image, a headline treatment, a layout choice tied to the business). Avoid the
  generic template look: identical rounded cards for everything, decorative gradients, a label above
  every heading, fake dashboards, stock smiling people that are not the business.
- Accessibility: headings in order, alt text, labels, contrast, focus visible, reduced motion respected.

## Build

- **Self-contained HTML**: one file, inline CSS, system or web-safe fonts (or the brand's licensed web
  font), no tracking scripts, images as `<img>` with descriptive alt and a clear placeholder path
  (`images/hero-pilates-class.jpg`) and a list of photos to provide.
- **For a platform** (WordPress, Wix, Shopify, Squarespace…): the same content as sections/blocks with
  headings, text, button labels and links, in the order to build them.
- Forms: minimal fields, labels, privacy notice, a clear success message. Point the action to the
  owner's real form service; never invent an endpoint.

## Before handing over

- [ ] Every fact verified (profile/owner) or a visible placeholder
- [ ] No invented reviews, numbers, superlatives, urgency
- [ ] CTA links real (tel:, wa.me, booking URL from the profile)
- [ ] Title and meta description written
- [ ] Mobile layout and contrast checked (rendered if possible; otherwise say not rendered)
- [ ] List of placeholders and photos the owner must provide
