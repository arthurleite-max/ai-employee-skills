# Fit score (0–12)

Four criteria, 0 to 3 each. Write each score and the sum.

| Criterion | 0 | 1 | 2 | 3 |
|---|---|---|---|---|
| Audience fit | Not the owner's customers | Some overlap | Clear overlap | Same customers |
| Topic relevance | Unrelated | Loosely related | Related | Exactly the owner's topic |
| Reach (for this business) | Tiny or unknown | Small | Medium | Large and real (engagement, not just followers) |
| Recent activity | Inactive 6+ months | Active 3–6 months ago | Active this quarter | Active this month |

- **Total** = sum of the four (show the sum: 3 + 2 + 2 + 3 = 10).
- **Contact**: is there a public business channel? If not, the next step is "find a public channel",
  not "guess an email".
- **Tie-break**: higher audience fit first.
- 9–12 approach now · 6–8 approach if capacity · 0–5 skip for now.
