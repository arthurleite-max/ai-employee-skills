# Build: file by file

| File | What goes in | Rule of thumb |
|---|---|---|
| `SKILL.md` | Front matter (`name` = folder name, kebab-case; `description` ≤ 1,024 characters with who, what, safety, triggers), the job, non-negotiable rules, levels, modes, main task steps, what not to do, file list | Every file it cites must exist |
| `setup.md` | First conversation: what it can do here, questions in short blocks, write the profile, wait for a yes | 5–10 minutes, "skip" accepted |
| `reference/*.md` | One topic per file (method, safety, pitfalls, examples); short tables | Read only when the mode needs it |
| `templates/*.example.*` | Profile and other inputs, filled with fictional data | Real-looking, never real |
| `scripts/*.py` | Optional helper: standard library, read-only, prints Markdown, `--json` option, clear errors | Handles both `;` and `,` CSV and the user's language headers |
| `assets/` | Example inputs and the script's outputs, generated by the script | Regenerate after every script change |
| `PASTE-INTO-ANY-AI.md` | Compact edition (see `compact-edition.md`) | Under 8,000 characters |
| `INSTALL.md` | A prompt the user pastes into their AI: paths for coding agents, apps with skills, projects or custom assistants, plain chat | Never asks for passwords |
| `README.md` | Promises, works with any AI, install options, first use, what to ask, safety, file table | Readable by a non-technical owner |
| `TUTORIAL.html` | One page: benefits, how it works, an example, what to ask, install tabs, first use, safety, FAQ | Works offline, light and dark |
| `LICENSE.md` · `CREDITS.md` | Licence text; credits table | Licence decided by the owner |

Internal files (origin table, analysis, test kit, results) live **outside** the public folder.

`scripts/new_skill.py <name> "<Title>"` creates all of the above with TODO markers; `package.py` refuses to
pack while any TODO remains.
