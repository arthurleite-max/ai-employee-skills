# Titles

The title and the thumbnail are one unit: **same promise, different words.**

## Checks for every title

| Check | Rule |
|---|---|
| Length | ≤ 60 characters (desktop search truncates after); the subject in the first 40 (mobile feeds cut there) |
| Specific | A number, an object, a name, a time ("5 minutes", "1/2-inch valve") beats an adjective |
| Truthful | The video delivers exactly what the title promises, early |
| No fake proof | No invented view counts, results, endorsements or credentials |
| Not the thumbnail | Shares no more than one word with the thumbnail text |
| Clean | At most two ALL-CAPS words; at most one emoji (often none); no "!!!" |
| Searchable | Includes the words people type for this problem (for search-driven niches) |
| Voice | Sounds like the owner |

## Patterns

| Pattern | Example (fictional) |
|---|---|
| Problem → fix + constraint | "Sink still clogged? Fix it without chemicals" |
| Mistake | "The mistake that makes your sealant crack again" |
| Number | "3 signs your water heater element is dying" |
| Comparison | "Silicone or acrylic sealant: which lasts in a shower?" |
| Time/cost | "Change a light switch in 10 minutes (no electrician)" |
| Question | "Why does my circuit breaker keep tripping?" |

## Ten, then three

Write ten different titles (different patterns, not ten versions of one). Check each. Show all ten
with their character count and any issue; recommend the top three and pair each with a thumbnail idea.
`python scripts/ytlint.py titles titles.txt --thumb "THUMB TEXT"` checks the mechanics.
