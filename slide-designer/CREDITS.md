# Credits

The Slide Designer is original text and code, inspired by ideas from open community projects. No files
from these projects were copied. Thanks to their authors:

| Project | License | Idea used |
|---|---|---|
| [hugohe3/ppt-master](https://github.com/hugohe3/ppt-master) | MIT | A real, editable PowerPoint made of native shapes, not pictures of slides |
| [anthropics/skills](https://github.com/anthropics/skills) (pptx) | see repository | Building and checking .pptx files as part of a skill |
| [icip-cas/PPTAgent](https://github.com/icip-cas/PPTAgent) | MIT | Research → structure → slides, with a review step |
| [zarazhangrui/frontend-slides](https://github.com/zarazhangrui/frontend-slides) | MIT | Visual polish when HTML is enough |
| [presenton/presenton](https://github.com/presenton/presenton) | Apache-2.0 | Slide plan as structured data (JSON) that a builder turns into a deck |

Projects under copyleft licences (AGPL) were looked at for ideas only; nothing from them is included.

The folder follows the open Agent Skills format (`SKILL.md`), documented at
[agentskills.io](https://agentskills.io).
