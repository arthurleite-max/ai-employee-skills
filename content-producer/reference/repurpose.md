# One piece into many

## From one source

| Source | Becomes |
|---|---|
| Long video / talk (transcript) | 3–5 short clips (timecodes), a carousel of the key points, 3 captions, a quote card, a newsletter paragraph |
| Article / blog post | Carousel, LinkedIn post, 3 short captions, a short-video script |
| Carousel | Reel script, a single-image post with the main point, a Story sequence |
| Customer question answered by the owner | Short video, carousel, FAQ post |

## Rules

- Use only what is in the source. Anything new (a number, an example) is a placeholder to confirm.
- Quote cards: real sentences from the source, attributed, unchanged (trim only).
- Adapt to each platform (length, first line, format), don't paste the same text everywhere.
- Space the pieces in the calendar; mark them as "from: [source]" in memory.
