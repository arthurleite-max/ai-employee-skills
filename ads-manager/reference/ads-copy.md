# Writing new ads

- Start from what works: the ad with the best cost per real customer; keep its offer, vary one thing.
- Each variation changes one element (hook, visual, call to action) so the result is readable.
- Hook in the first line: a benefit or a situation the customer recognises, not a question about their
  body, money or health.
- Proof the owner can show: reviews (with permission), years in business, guarantees they really offer.
- Clear call to action and the real offer (price, trial, deadline only if true).
- Format per variation: Primary text · Headline · Description · CTA · Visual idea · What it tests.
- Search ads: headlines up to 30 characters, descriptions up to 90; include the keyword naturally.
