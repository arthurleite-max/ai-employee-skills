# Credits

The Support Agent is original text and code, inspired by ideas from open community projects. No files
from these projects were copied. Thanks to their authors:

| Project | License | Idea used |
|---|---|---|
| [anthropics/knowledge-work-plugins](https://github.com/anthropics/knowledge-work-plugins) (customer-support, ticket-deflector) | Apache-2.0 | Triage by priority, replies grounded in the written policy, escalation brief |
| [nbashaw/claude-cs](https://github.com/nbashaw/claude-cs) | MIT | Building support automation around each business's own answers |
| [tgoai/tgo](https://github.com/tgoai/tgo) | see repository | Knowledge base answers with a person always able to take over |
| [chatwoot/chatwoot](https://github.com/chatwoot/chatwoot) | see repository | One conversation per customer across channels; hand-off to a person |

Some projects without a stated licence were looked at for ideas only; nothing from them is included.

The folder follows the open Agent Skills format (`SKILL.md`), documented at
[agentskills.io](https://agentskills.io).
