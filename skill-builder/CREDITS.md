# Credits

The Skill Builder is original text and code. Its method comes from building and testing a series of
business skills, and it was inspired by ideas from open projects. No files from these projects were
copied. Thanks to their authors:

| Project | License | Idea used |
|---|---|---|
| [anthropics/skills](https://github.com/anthropics/skills) (skill-creator) | Apache-2.0 | Drafting a skill, testing it with prompts and improving it in rounds |
| [agentskills.io](https://agentskills.io) | open specification | The `SKILL.md` folder format shared by many AI tools |
| [VoltAgent/awesome-agent-skills](https://github.com/VoltAgent/awesome-agent-skills) | see repository | Studying many published skills before writing a new one |
| [promptfoo/promptfoo](https://github.com/promptfoo/promptfoo) | MIT | Testing the same instructions across several models before release |

The folder follows the open Agent Skills format (`SKILL.md`), documented at
[agentskills.io](https://agentskills.io).
