# Charts that tell the truth

| Message | Chart |
|---|---|
| Compare categories | Bars (start the axis at zero) |
| Change over time | Line or bars by period |
| Parts of a whole (2–5 parts) | Stacked bar or simple pie, only if parts add up to 100% |
| One key figure | Big number with a caption and source |

Checks before charting
- The data matches the source and the headline.
- Parts of a whole add up to 100% (or explain: "multiple answers allowed").
- Same period and unit across bars.
- Label values directly; avoid legends when possible; no 3D.
