# Discovery

## The brief (one page)

| Field | Example |
|---|---|
| Job | "Chase unpaid invoices politely and on time" |
| User | Owner of a small business, not technical, uses a free chat app on the phone |
| Promises (3–5) | Finds what is overdue · drafts the right reminder for each customer · respects disputes and contact rules · tells me what needs me today |
| Must never happen | Asks for a disputed amount · emails someone who asked not to be emailed · sends without approval |
| Inputs | Invoice list (pasted or file), today's date, contact rules |
| Outputs | Overdue table, one draft per customer, list of what needs the owner |
| Frequency | Weekly |
| Levels | Chat (paste) · code (CSV → table) · agent (reads the accounting export) |

## Questions that find the real job

- "Walk me through the last time you did this by hand." (steps, order, where it hurts)
- "What did you get wrong once that cost you?" (becomes a rule)
- "What would you never let an assistant do alone?" (approval points)
- "How do you know it was done well?" (becomes a check)
